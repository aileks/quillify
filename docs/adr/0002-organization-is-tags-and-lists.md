# Organization is tags and lists, not shelves

Reader-owned organization in Quillify is exactly two structures: Tags (unordered, cross-cutting labels) and Lists (named, ordered, curated groups). Genre remains descriptive book metadata rather than becoming user-owned organization. Goodreads-style unified shelf model was rejected; one concept carrying both filtering and ordering forces shelves to be everything at once. Merging or splitting them after data accumulates is costly. Goodreads shelves are imported as tags, never as lists.
